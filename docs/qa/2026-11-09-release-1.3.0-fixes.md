### Q-02 앱 안에서 권한 허용 직후 월 캘린더 — FAIL → 수정 → PASS
- 재현(2/2): 할일 권한 초기화 → 재실행 → + → 할일 → "허용" → 저장. 저장은 됐는데(할일 탭엔 보임) 월 캘린더엔 기존 할일까지 칩 0개. 백그라운드 → 복귀로도 안 풀리고 재실행해야 보임
- 원인(임시 로그): 허용 뒤에도 `EKEventStore.authorizationStatus(for: .reminder).rawValue == 0`. 월 VM은 상태만 읽어(`currentAccess`) 조회를 건너뛰었다. 할일 탭은 `requestAccess`가 프롬프트 API의 true를 받아 정상이었다
- 일정 권한도 같다: 허용 뒤 `raw=0`
- 정정: 처음엔 일정 쪽도 "비어 있음"으로 봤다. 하지만 그 실행에선 `alert accept`가 "허용 안 함"을 눌렀다(TCC Calendar=0). 버튼을 이름으로 골라 다시 확인했다
- 수정 92f773e: EventKit 저장소 두 개가 이번 실행의 허용을 기억해(`grantedThisLaunch`) `currentAccess`에 반영
- 재검:
  - 일정: 허용 뒤 `raw=0`인데 granted로 읽혀 11월 30건을 조회했고, 칩은 1초 안에 15개 보였다
  - 할일: 허용 → 저장 → 재실행 없이 칩 10개(기존 + 새 할일) 표시
