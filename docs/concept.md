# cue — 앱 컨셉

## Story

Cue는 할 일 목록이 아니라, 지금 잊으면 안 되는 하나를 계속 보여주는 작은 신호다.

사람은 하루 전체를 계속 기억하고 싶지 않다. 해야 할 일, 잠깐 떠오른 생각, 나중에 다시 봐야 하는 메모, 지금 붙잡고 있어야 하는 한 가지를 매번 다시 떠올리는 일은 피곤하다.

Cue는 사용자가 직접 띄워둔 하나를 잠금화면, Dynamic Island, Live Activity 위에 조용히 남겨둔다. 앱을 열지 않아도 보이고, 알림처럼 지나가버리지도 않는다. 그냥 화면 위에 계속 떠 있으면서 사용자가 잊지 않게 만든다.

- 다음 할 일
- 잊으면 안 되는 메모
- 잠깐 뒤 다시 봐야 하는 생각
- 집중하고 싶은 한 가지
- 놓치면 안 되는 작은 메모

Cue의 역할은 사용자를 압박하는 것이 아니라, 사용자가 직접 정한 신호를 계속 보이게 하는 것이다. 복잡한 관리 시스템도, 자동 추천도 아니다. 지금 화면에 남겨두고 싶은 것을 가장 잘 보이는 곳에 고정해두는 앱이다.

> 하루를 관리하는 앱이 아니라, 지금 잊으면 안 되는 하나를 계속 보여주는 앱.

## Product Flow

Cue의 기본 경험은 하나를 띄워두는 것이다.

사용자는 지금 잊으면 안 되는 할 일, 메모, 집중할 대상을 Cue로 만든다. Cue는 Live Activity로 잠금화면과 Dynamic Island에 계속 남아 있고, 사용자는 앱을 열지 않아도 지금 봐야 할 것을 확인할 수 있다.

여기서 Cue는 두 방향으로 확장된다.

### Timeline

`Timeline`은 사용자가 만든 Cue들을 시간 순서대로 보여주는 화면이다.

하루 안에서 어떤 Cue를 언제 띄웠는지, 다음에 어떤 Cue를 봐야 하는지, 이미 지나간 Cue가 무엇인지 한 줄 흐름으로 볼 수 있다. Cue가 "지금 하나를 계속 보여주는 신호"라면, Timeline은 그 신호들이 하루 안에서 어떻게 이어졌는지 보여주는 기록이다.

- 지금 떠 있는 Cue
- 다음에 볼 Cue
- 오늘 이미 지나간 Cue
- 특정 시간에 다시 띄울 Cue

### Focus / Pomodoro

`Focus Cue`는 Cue를 집중 시간과 연결하는 기능이다.

사용자는 하나의 Cue를 띄운 뒤, 그 Cue에 집중 시간을 붙일 수 있다. 예를 들어 25분 동안 "기획서 쓰기"를 띄워두고, 시간이 끝나면 짧은 휴식으로 넘어간다. Cue는 단순한 타이머가 아니라, 타이머가 도는 동안 계속 봐야 하는 집중 대상이다.

추후에는 앱 포커스 기능과 연결된다. 집중 시간이 시작되면 사용자가 정한 앱을 잠시 막고, Cue에 적어둔 일로 다시 돌아오게 만든다.

- Pomodoro: Cue에 붙는 집중 타이머
- Focus Cue: 집중 중 계속 보이는 Cue
- App Blocking: 집중 중 방해 앱 차단
- Stay on Cue: 다른 앱으로 흐르지 않게 붙잡아주는 모드

## Visual Core

Cue의 핵심 비주얼은 `Signal Dot`이다.

작은 점 하나가 켜지고, 주변에 얇은 파동이나 링이 퍼진다. 이 점은 "지금 볼 것", "지금 할 것", "다음으로 넘어갈 순간"을 의미한다.

## Pro Idea

`Cue Pro` 영역에는 행성보다 신호 오브젝트가 어울린다.

추천 오브젝트:

- 작은 유리 구체
- 구체 안의 밝은 점
- 바깥으로 퍼지는 얇은 ring 1-2개
- 캡슐 위에 살짝 떠 있는 형태

의미:

> 더 선명한 신호. 더 놓치지 않는 하루.
